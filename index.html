다른 기기와 연결하기

처음 연결한 기기에서 코드를 복사해 다른 기기에 입력해요. 이 코드를 가진 사람은 기록을 열 수 있으니 가족끼리만 보관해주세요. 연결 코드는 GitHub에 저장되지 않아요.

연결하면 이 기기의 기존 학습 기록도 합쳐요. 코드가 사라지면 다른 연결된 기기나 백업 파일이 필요해요.

학습 방법과 기록 보관

① 3분 암기 → ② 뜻을 보고 직접 입력 → ③ 복습 날짜에 다시 확인해요. 같은 날 여러 번 맞혀도 복습 단계를 건너뛰지 않아요.

힌트 없이 맞히면 1일 → 3일 → 7일 → 14일 간격으로 복습해요. 오답·힌트 사용은 10분 뒤 다시 확인해요. 이 간격은 조절 가능한 학습 규칙이며 암기 속도를 보장하지 않아요.

단어장은 기존 동기화를 사용해요. 새 오답·암기 기록은 이 브라우저에 저장되며, 클라우드 연결 후에는 암호화해서 함께 저장해요. 인터넷이 끊겨도 이 기기에 기록하고 연결되면 다시 저장합니다. 단어 관리의 백업 저장에는 단어장과 학습 기록이 함께 들어가요.
